# АРМ ЭТЛ для Android — автосборка двух APK через GitHub

Этот проект автоматически собирает **два готовых установочных файла Android (`.apk`)** из ваших веб-приложений:

1. **`ARM_ETL_Electrician_v1.0.apk`** — *АРМ ЭТЛ Электромонтёр* (полевой клиент: сервер, офлайн-очередь, камера для QR и фото дефектов, чек-листы ТО/ТР, испытания, выгрузка очереди).
2. **`ARM_ETL_Mobile_Offline_v1.2.apk`** — *АРМ ЭТЛ Автономный* (полная автономная база IndexedDB, 1 871+ единиц оборудования, протоколы, наряды-допуски, выгрузка `.doc` и синхронизация `.json` по Bluetooth).

## Что уже настроено внутри обёртки Android
- Локальный HTTPS-контекст (`WebViewAssetLoader`) — работают камера (`getUserMedia`), `BarcodeDetector` (QR), `IndexedDB` и `localStorage` полностью без интернета.
- Разрешён HTTP-трафик (`usesCleartextTraffic="true"`) для подключения клиента электромонтёра к локальному серверу ПК (`http://192.168.x.x:8080`).
- Нативное сохранение файлов `.doc` и `.json` в папку **Загрузки / ARM_ETL** с автоматическим открытием системного меню «Поделиться» (Bluetooth, мессенджеры, Word).
- Доступ к камере для QR-сканера и фото дефектов, а также выбор `.json` файлов синхронизации.

## Как получить готовые APK за 3 минуты (без установки программ)
1. Распакуйте архив `ARM_ETL_Android_APK_Builder.zip` в любую папку на ПК.
2. Зайдите на [github.com](https://github.com) (войдите или создайте бесплатный аккаунт) и нажмите **New** (создать новый репозиторий, можно **Private**).
3. На странице пустого репозитория нажмите **uploading an existing file**, перетащите **все файлы и папки из распакованной папки** (включая скрытую папку `.github`!) и нажмите **Commit changes**.
   - *Важно:* если загружаете через браузер, убедитесь, что в Windows включено отображение скрытых папок, чтобы папка `.github/workflows/build-apk.yml` тоже загрузилась (либо создайте файл `.github/workflows/build-apk.yml` прямо в интерфейсе GitHub кнопкой *Add file → Create new file*).
4. Откройте вкладку **Actions** в репозитории → выберите запуск **Build ARM ETL Android APKs** → подождите 2–3 минуты → внизу страницы в блоке **Artifacts** скачайте архив **`ARM_ETL_Android_APKs`** с обоими готовыми `.apk`.

## Установка на телефон Android
1. Перекиньте оба `.apk` на телефон (по кабелю, Bluetooth или в мессенджер).
2. Нажмите на файл `.apk` на телефоне и при запросе разрешите установку из неизвестных источников.
